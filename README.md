# 📦 qz-real-estate_propReslling_backend

A backend system for managing real estate property reselling, built with **CodeIgniter 4**. It includes features like JWT authentication, user roles (Admin, Buyer, Seller), and secure APIs.

---

## 🚀 Features

- User registration and login
- Role-based access (Admin, Seller, Buyer)
- JWT token-based authentication
- Modular structure with CodeIgniter 4
- Secure and scalable RESTful APIs

---

## 🛠 Tech Stack

- PHP 8+
- CodeIgniter 4
- MySQL
- Firebase JWT
- Composer
